Automated release cho .NET ERP legacy

Case study

Thay quy trình deploy tay (build IDE → copy tay lên server) của một hệ ERP / hoá đơn .NET lớn bằng pipeline tự động: build → backup có phiên bản → deploy → smoke test, cổng release theo tag để an toàn cho hệ thống production.

  • Loại rủi ro con người: backup theo timestamp + rollback 1 lệnh + loại trừ config production.
  • Cổng release theo tag/duyệt tay — hợp hệ thống hoá đơn/phân quyền nhạy cảm.
  • Kèm luồng auto-fix có kiểm soát (PR-gated) — máy đề xuất, người duyệt.
