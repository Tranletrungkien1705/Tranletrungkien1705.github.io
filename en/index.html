cicd-k8s-lab — GitOps on Kubernetes

Flagship Live demo

A complete, modern CI/CD system, hand-built and running for real: pushing code auto-triggers build → push image → update manifest → Argo CD auto-syncs → rolling update on Kubernetes, with Prometheus/Grafana monitoring.

Impact: manual deploy (build in IDE → hand-copy to server, ~15 min each, easy to misconfigure) → just 1 git push, zero manual steps, zero-downtime, rollback = git revert.

  • Closed GitOps loop: 1 git push → new version on the cluster, hands-off.
  • Diagnosed & fixed real issues: WSL RAM limits, server-side apply for CRDs, YAML bug breaking the pipeline.
  • k3d + private registry + ingress-nginx + Argo CD + kube-prometheus-stack, stood up with one script.
